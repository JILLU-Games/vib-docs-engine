## 2. Where to Route Your Request

| Request Type | Official Channel | Notes |
| :--- | :--- | :--- |
| **Bug Report (Engine / Build / UI)** | [GitHub Bug Report Form](.github/ISSUE_TEMPLATE/bug-report.yml) | Include reproduction steps and output from `npm run verify`. Never include tokens or private URLs. |
| **Feature Request / Enhancement** | [GitHub Feature Request Form](.github/ISSUE_TEMPLATE/feature-request.yml) | Proposals must preserve the static, config-driven architecture. |
| **Product & Technical Support** | **[support@vibtools.io](mailto:support@vibtools.io)** | Direct technical assistance for Vib Tools products and documentation portals. |
| **Security Vulnerability Disclosure** | **[support@vibtools.io](mailto:support@vibtools.io)** | Follow [`SECURITY.md`](SECURITY.md) for private disclosure. Never post vulnerabilities in public issues. |
| **General Inquiries, Partnerships & Press** | **[hello@vibtools.io](mailto:hello@vibtools.io)** | Company inquiries, custom software development, and partnership requests. |
