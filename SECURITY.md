# Security Policy

## Reporting a vulnerability

Please do not publish suspected vulnerabilities, exploit details, credentials, or private repository information in a public issue or pull request. Send a private report to [support@vibtools.io](mailto:support@vibtools.io) with:

- Affected repository, component, and version/commit if known.
- A concise description of impact and conditions required.
- Safe reproduction details that do not access other users' data.
- A way to contact you for clarification.

Do not include live tokens, passwords, private keys, or personal data in the report. This repository publishes no response-time guarantee; coordinate disclosure privately with maintainers.

For vulnerabilities in another Vib Tools product, follow that repository's `SECURITY.md` if present. If no repository-specific policy exists, use the private support address above.
