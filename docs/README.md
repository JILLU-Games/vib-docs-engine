# Operator and Portal Guides

This tracked directory contains verified instructions for operating `vib-docs-engine` and using the generated documentation portal. Product-authored guides normally live in each product repository's `docs/` folder; this repository's `docs/` is the engine's own operator documentation and local sync fixture.

## Guides

- `index.md`: local workflow, config, search, endpoints, and deployment overview.
- `adding-projects.md`: product setup, presets, CLI, and rebuild hooks.
- `deployment.md`: portal export, Cloudflare Pages, Docker/Coolify, and launch checks.
- `portal-user-guide.md`: Hub, search, and docs reader behavior for portal readers.
- `MANIFEST.md`: direct file/subfolder inventory.

Keep instructions aligned with checked-in UI and scripts. When behavior is unknown or not implemented, state that explicitly rather than infer it.
